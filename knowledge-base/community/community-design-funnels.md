# Community Design & Funnel Architecture

## Platform selection
- **Skool:** best for course + community + gamification in one; simple, low friction.
- **Whop:** best for selling access + bundling apps/tools; strong checkout + affiliate.
- **Circle/Discord:** more customization/engagement surface; more setup overhead.
Choose by primary job-to-be-done: structured learning → Skool; access/tooling
marketplace → Whop.

## Community setup SOP (Skool example)
1. Create the group; set a clear one-line promise in the headline ("Get your first
   {result} in 30 days").
2. Build the **welcome flow**: pinned welcome post → "introduce yourself" thread →
   a single "start here" classroom module.
3. Structure the **classroom** as a path, not a library: Module 0 (quick win) →
   Module 1 (core skill) → ascension module (locked behind progress or tier).
4. Set up **gamification**: points for posts/comments, unlock levels that reveal
   bonus content — engagement compounds retention.
5. Define **rules + rituals**: weekly live call, weekly "win of the week" thread,
   daily prompt. Rituals create the return habit.

## Funnel architecture: low-ticket → high-ticket
- **Lead magnet (£0):** a specific, fast win (template, mini-training) → captures email.
- **Tripwire (£7–47):** low-friction paid product → converts a lead into a *buyer*
  (the single most important status change in the funnel).
- **Core community (£49–99/mo):** recurring access + course + group.
- **High-ticket ascension (£2k–10k):** done-with-you / mastermind, sold via
  application + call to proven members.

## Funnel logic
- Optimize for **buyer creation early** — a £19 buyer converts to high-ticket far
  better than a free lead. The tripwire's job is identity change, not profit.
- **Ascend on results, not time** — trigger the high-ticket invite when a member
  hits a milestone (first client, first £1k), so the offer lands at peak belief.

## Engagement loops (retention engine)
1. **Onboarding loop:** new member → quick win in <48h → first post celebrated.
2. **Habit loop:** weekly live + daily prompt → predictable reason to return.
3. **Status loop:** points/levels + public wins → members compete and stay.
4. **Outcome loop:** members get results → results become testimonials → fuel
   acquisition → new members. The whole flywheel.
Churn is fought in week 1: a member who gets a win and posts it in the first 7 days
retains dramatically better than a lurker.
